# Project Rebound display gallery

Upload approved gallery photographs to this folder. The television webpage automatically detects JPG, JPEG, PNG, WebP, and GIF files here and checks for changes every five minutes.

Use numbered, descriptive filenames to control the display order and caption, for example:

- `01-community-lunch.jpg`
- `02-rebound-scholar-orientation.jpg`
- `03-graduation-celebration.jpg`

The number controls the order. The remainder of the filename becomes the on-screen caption. Do not upload this README as an image.

Before uploading an identifiable student photograph, confirm that Project Rebound has written permission for public display. Do not use filenames containing student IDs or confidential information.
