# Approved display images

Upload only photographs or graphics approved for public display on the Project Rebound Center televisions and public GitHub Pages site.

Recommended image format: JPG, PNG, or WebP. Use short filenames without spaces.

## Temporary stock placeholders

The live display currently bundles these free-to-use Pexels photographs as temporary examples, so the television does not depend on third-party image hotlinks:

- Welcome screen: [college students walking together on campus](https://www.pexels.com/photo/a-group-of-college-students-walking-at-the-campus-7683887/)
- Scholar Spotlight: [adult student in a sunlit classroom](https://www.pexels.com/photo/adult-student-in-a-sunlit-classroom-37811252/)

The people pictured are stock models and are not Project Rebound students or CSUSB program participants. Replace these photographs with authentic, approved Project Rebound images when available. Obtain written permission before displaying an identifiable student photograph.

The bundled `project-rebound-logo.svg` contains the [official Project Rebound logo supplied by CSUSB](https://www.csusb.edu/sites/default/files/upload/image/2025/PR%20New%20Logo.jpg). The SVG wrappers preserve the original images inside text-based repository files; they are not redesigned or altered logos.
